## Confirmed 4 Oct — the HR-drift pattern, and why progression still continues

28 Sep–4 Oct's three running sessions all showed HR climbing within the
session (clearest in Sunday's long run: sustained Z3 for 3 of 4 reps while
power stayed flat — classic cardiac drift from duration/fatigue, not
pushing harder). Talked it through directly: Alex's read is that this is
consistent with still rebuilding the aerobic base after the layoff, not a
red flag, and wants progression to continue unless there's a good reason
not to.

That read holds up: power staying flat while HR climbs is the textbook
signature of aerobic decoupling from a base that's still being
established at this duration — not of pushing too hard — and the fix for
that is exactly what's already happening (consistent easy-paced volume),
not backing off it. No knee pain or swelling either, so the physical gate
stays clean.

So Tuesday's walk-shrink step below stays as drafted, not escalated
further, and doubles as the actual read on this: if HR still climbs early
even with less recovery, that's the signal the base needs more time before
this axis moves again; if it holds steadier than 29 Sep/4 Oct did, that
supports the "still settling in" read and the walk can keep shrinking next
time. Either outcome is useful information, not a pass/fail.

## Revised 29 Sep — correcting how "progression" was being framed

The original draft paused ratio progression completely this week, on the
reasoning that the back-to-back was the week's one new stimulus and
hard/easy alternation says introduce one thing at a time. That was too
narrow — it read as "nothing progresses this week," which isn't right.

**The actual picture:** there are two separate progression axes in the
run/walk method, not one. So far only one of them has moved — the run
segment has grown (1mi → 1.25mi over the last two sessions) while the walk
segment has sat fixed at 250m. The other axis — shrinking the walk segment
itself — hasn't been touched yet, and it's the more direct route toward
genuinely continuous running (the question that prompted this revision).
Tuesday 6 Oct, a normal build day four days clear of the back-to-back, is
a good place to move that axis instead of the run segment — real
progression, still only one new variable introduced this week, just not
the same variable as last time.

The back-to-back weekend itself (Sat/Sun) still holds the proven
1.25mi:250m structure. That's deliberate, not a pause: the thing actually
being tested there is whether Saturday's HR stays in the prescribed range
this time, not the run/walk ratio's limits. Changing the ratio and
expecting clean effort control in the same session would confound that
test — so it holds steady there specifically to keep that read clean.
