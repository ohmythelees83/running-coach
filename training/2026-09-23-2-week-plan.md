# Training Plan — 23 Sep to 6 Oct 2026 (2 weeks)

Goal race: Centurion Thames Path 100, May 2027 (~8 months out)
Built from: `reviews/2026-09-23-strava-baseline-review.md`

## Context this plan is built on
- Rebuilding after a multi-year reduction in volume (2023–2025) and ~11 weeks
  post knee arthroscopy — cleared to run, watch for swelling/pain.
- Current baseline: ~13–15 mi/week across 3 run/walk sessions, steadily
  progressing the run segment (currently ~1 mile run : 250m walk).
- 6 Sep session showed what happens when effort/terrain spikes too early
  (Zone 4 HR, high elevation) — this plan deliberately avoids repeating that
  until more clean weeks are banked.
- Wednesdays: office day in London — easy only, no structured session.
- Turbo trainer available — used here for cross-training/recovery days.

## HR targets for this block
- **Easy / walk segments:** ≤122 bpm (Z1)
- **Run segments (structured sessions):** 123–135 bpm (Z2) — this is the
  main aerobic training zone for this block
- **Avoid sustained Z3+ (136 bpm+)** except brief unavoidable hill surges —
  if HR sits above 135 for more than a minute or two, walk it back down
- **Turbo (easy spin):** Z1–Z2 effort, conversational, no structure needed

## Progression rule
Continue extending the run segment / shortening the walk segment **only if**
the prior session produced no knee swelling or pain. If anything flares up,
drop back one step in the run:walk ratio and hold there.
