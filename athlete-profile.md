## Coaching Philosophy
Built 2026-09-24 from three inputs: research into three coaching influences
Alex named (Scott Johnston/Uphill Athlete, Tom Evans, Robbie Britton), a
structured interview, and an 8-week Strava data analysis. This is a genuine
synthesis, not any one coach's system — see "Influences and Reasoning" below
for exactly what came from where.

### Core Principles
1. **Aerobic base and muscular durability come first; speed is earned, not
   assumed.** (Johnston) No quality/speed sessions until the aerobic base and
   muscular-endurance foundation are genuinely re-established — currently
   zero, by Alex's own request, with the door open later.
2. **Long-run duration is built in phases, not assumed.** (Britton ⟷ Evans,
   deliberately balanced) Britton doesn't trust the body to repeatedly
   absorb long continuous efforts and caps around 2–2.5h; Evans proves
   multi-hour continuous running is trainable. Resolution: stay
   Britton-conservative now given the layoff and recent knee surgery, and
   extend toward genuinely long continuous running later in the block as
   durability is actually earned in training — not because Alex once
   sustained 60mi/week, but because that history shows the *instinct* to
   build isn't wrong, only the current starting point and pace need
   discipline.
3. **Fatigue-specific running is trained on purpose, through whichever tool
   fits the week.** (Britton's in-run progressive effort + back-to-back
   weekends already in use) Running on tired legs is genuinely specific to
   Thames Path 100 — trained either through pace-building in the back half
   of a long run or through back-to-back days, chosen based on that week's
   real availability, not a fixed template.
4. **Recovery is governed by symptoms, not by the numbers.** Overrides
   Johnston/Evans' more data-driven load models: Alex's knee issue was not
   clearly load-triggered (it flared off the bike too), so swelling/pain
   checks after every session take priority over what a volume or HR chart
   says is "safe."
5. **Fuel is trained like fitness — periodized, gradually built toward race
   demands, and never just macros.** (Evans' periodized fasted/fed training
   blended with Britton's food-as-psychology view) Start conservative and
   test gut tolerance in training rather than adopting either coach's
   race-day numbers untested.

### Training Structure
- **Current phase: Base.** Rebuilding aerobic volume and the run:walk ratio,
  zero quality sessions, consistent with Johnston's base-first model.
- **Weekly shape:** fully flexible, re-derived each week (see `plan-my-week`
  skill) — Mon/Fri default rest or turbo, Wed easy-only (office day), one
  progression-focused run/walk session, long run on Sat or Sun depending on
  availability.
- **Block structure:** ~3 build weeks to 1 recovery week (~20–30% volume
  cut), matching the periodization research already baked into
  `plan-my-week`.
- **Phase progression toward May 2027:** Base (now) → muscular-endurance
  work introduced late in base/into build (Johnston-style, once the aerobic
  base is solid) → Build phase layering in tired-leg quality (Britton
  in-run progression, back-to-back weekends, eventually some Evans-style
  speed once the foundation supports it) → race-specific prep (flat,
  towpath-specific long continuous efforts, full fueling rehearsal) → taper.

### Volume and Intensity
- Effectively 100% easy/aerobic right now (zero quality sessions);
  intensity distribution shifts toward a genuine 80/20 split only once
  quality is reintroduced, not before.
- ~10% weekly volume increase as the default pace (see `plan-my-week` for
  the full reasoning and its limits) — a sane guideline for this rebuild,
  not a guarantee.
- Alex's historical peak of ~60mi/week is a long-term reference point, not
  a near-term target — current volume is ~14–16mi/week, and closing that
  gap safely is a multi-month project, not a multi-week one.
- **Load monitoring gap to close:** Strava data shows no repeated
  fixed-effort benchmark to actually track fitness trend over time.
  Introduce an occasional fixed-effort check (e.g. same easy route/HR cap,
  monthly) so progress is measured, not assumed.

### Signature Approaches
1. **Run/walk ratio progression** — Alex's own established method, extending
   the run segment and shrinking the walk segment as sessions stay
   symptom-free. Already validated by the graduated return from 31 August.
2. **In-run progressive effort** (Britton) — building pace through the back
   half of a long run, introduced once continuous running duration is more
   established, as the first "quality within endurance" tool before any
   formal speed work returns.
3. **Back-to-back long run weekends** — a recurring tool (not a one-off),
   building multi-day fatigue resistance specific to 100-mile demands,
   always as moderate/easy days until a track record of clean sessions
   justifies more.

### Recovery Philosophy
Recovery is active, not passive: turbo trainer sessions on default rest days
(Mon/Fri) keep the aerobic engine ticking without impact. A recovery week
every ~3–4 build weeks is planned, not reactive. Non-negotiable: any
swelling or pain stops progression immediately regardless of what the plan
says, given the knee issue's non-load-triggered pattern.

### Mental Approach
Coaching tone: a blend of tough love and encouragement, per Alex's own
preference. Given the DNF history, borrowing directly from Evans' own
turning point — his 2025 UTMB win followed dropping "I need to win" for "I
want to do my best." The framing for Thames Path 2027 is finishing well,
not erasing the DNF by force. Practically: expect winter mornings to be a
genuine friction point (Alex has said so directly) — default to
evening/lunchtime sessions in winter rather than relying on willpower
against early alarms. Turbo intervals are tolerated, not loved — kept
functional and purposeful, not used as a punishment tool.

### Fueling Philosophy
Periodized like Evans (train both underfed and fully-fueled scenarios
across long runs) but built up gradually from where Alex actually is, not
adopting elite race-day carb targets untested. Food choice treated partly
as psychological, per Britton — palatability over hours matters as much as
grams per hour. Specific carb-per-hour targets for Thames Path will be set
once gut tolerance is actually tested in training, not assumed from either
coach's numbers.

### What This Athlete Is Training For
The Centurion Thames Path 100, May 2027 — a largely flat towpath 100-miler
Alex has finished twice before and DNF'd on the most recent attempt. This is
a return/redemption goal, not a first attempt, being approached from a
genuine fitness rebuild: a multi-year reduction in training (low
testosterone, now treated with TRT) and a knee arthroscopy roughly 11 weeks
before this plan began. The runway is real (~8 months) but not generous
given the starting point — hence base-first, symptom-governed, and
deliberately paced.

  speed is earned late, not assumed — directly reflected in the current
  zero-quality base phase.
- **Evans** shaped the periodized fueling approach and, more importantly,

  forcing an outcome). His higher-volume, speed-inclusive model is
  deliberately not adopted wholesale right now — Alex's current state
  doesn't support it yet, though the phase progression leaves room for it

- **Britton** shaped the conservative long-run-length default and the

- **Alex's own data overrode the coaches** in one clear place: the
