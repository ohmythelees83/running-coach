## Key finding: the 6 September outlier

6 Sep stands out on every measure: nearly 3x the elevation gain of any other
session (365 ft), heart rate sustained at 151–160 bpm (Zone 4) for extended
climbing stretches, and relative effort roughly double every other run in the
block. This came ~9–10 weeks post-knee-arthroscopy — hard, hilly, high-HR
running earlier than ideal in a return-to-run window.

The very next session (8 Sep) shows a clear, deliberate pull-back: run:walk
ratio dropped from ~1km:250m to a full 1km:1km, and average HR dropped to 107
(lowest of the block). Whether self-directed or app-prompted, this was the
right response.

## Since the cutback: a clean rebuild

From 8 Sep to 20 Sep, the run segment has been progressively extended and the
walk break progressively shortened:

1km run : 1km walk → 1km run : 500m walk → 1km run : 250m walk → 1 mile run :
250m walk

Average HR on the run segments has crept up over the same period (107 → 129),
which likely reflects both the increasing run:walk ratio and rising effort,
not just drift — worth continuing to watch as volume increases, but not a
concern on its own at this stage.

## Baseline conclusions

- Current weekly volume: ~13–15 mi/week across 3 running sessions, fairly
  steady. This is a sensible, conservative starting point for the rebuild.
- Cross-training: ~1 Zwift ride/week (~30 min). Under-used relative to what's
  available (turbo trainer) — see 2-week plan for how we're using it.
- HR zones in use (Strava, manual): Z1 ≤122 · Z2 123–135 · Z3 136–150 ·
  Z4 151–165 · Z5 166+. These align closely with the July 2025 lab-tested
  lactate threshold (~122 bpm), so treated as broadly reliable for now.
- Hard/hilly efforts (Z3+) should stay rare and deliberate, not incidental,
  until several more clean weeks of rebuilding are banked and the knee has
  shown no swelling/pain across a range of terrain.
